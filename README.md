# LINE 帳號轉移後，聊天記錄還原一直轉圈怎麼辦？

## 適用情況

使用新手機登入 LINE，透過行動條碼轉移帳號後，畫面停在聊天記錄還原或備份還原的載入畫面，長時間轉圈、無法完成。

> **重要：**這不代表所有使用行動條碼轉移的情況都會發生。以下是可嘗試的排除方式，實際畫面和可用登入方式可能因手機系統、LINE 版本及帳號設定而不同。

## 嘗試重新登入與還原

### 1. 先保護舊手機上的資料

- **不要在舊手機的 LINE 中選擇「刪除資料」或其他會清除聊天記錄的選項。**
- 確認舊手機上的聊天記錄備份已完成，並確認新手機使用的是建立備份時相同的雲端帳號：
  - iPhone：iCloud
  - Android：Google 帳戶與 Google 雲端硬碟
- 確認備份日期和時間符合需求。若無法確認備份已完成，先不要清除舊手機上的 LINE 資料。
- 請留意：在新手機登入並轉移帳號，可能會使舊手機上的 LINE 登出。若舊手機已登出或帳號轉移狀態不明，不要反覆嘗試在兩台手機間登入；先確認帳號與備份狀態。

### 2. 重新安裝新手機上的 LINE

若已確認有可用的聊天記錄備份，可嘗試以下方式：

1. 在新手機解除安裝 LINE。
2. 重新從官方應用程式商店安裝 LINE。
3. 開啟 LINE，選擇登入。
4. 若你的地區、帳號及目前版本提供以電話號碼登入的選項，可選擇該方式，並依照畫面完成電話號碼驗證及帳號登入。
5. 登入後，依照畫面選擇還原聊天記錄備份。
6. 還原時，確認使用的是建立備份時相同的 iCloud 或 Google 帳戶，並保持網路穩定、手機電量充足。
7. 等待還原完成；過程中不要關閉 LINE 或切換登入帳號。

> **注意：**電話號碼登入並非所有地區或帳號都適用。若畫面沒有此選項，請使用 LINE 提供的其他登入方式，不要為了套用此步驟而更改或解除帳號綁定。

## 如果仍然無法還原

- 確認新舊手機的作業系統、LINE 版本及雲端備份帳號是否符合備份與還原需求。
- 確認網路連線穩定，並檢查新手機是否有足夠的可用空間。
- 不要在未確認備份存在前刪除舊手機上的 LINE 資料。
- 若仍持續卡在載入畫面，請先停止反覆登入或重新安裝，並聯絡 LINE 客服確認帳號及備份狀態。

## 提醒

重新安裝 LINE 或重新登入，不保證一定能修復還原問題。開始前，請先確認舊手機上的資料與雲端備份狀態，避免在備份不完整時清除仍可用的資料。
